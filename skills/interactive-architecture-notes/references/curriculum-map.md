# Architecture curriculum map (Türkiye)

This is a **navigation aid**, not a canonical catalogue. Course codes, ECTS and
semester placement change; verify the current Bologna/ÖBS page before quoting a
code in a note.

## Typical sequence

| Year | Studio | History / theory | Technology / environment | Representation / digital |
|---|---|---|---|---|
| 1 | Mimari Tasarım I (temel tasarım) | Mimarlık Tarihi I (antik–ortaçağ) | Yapı Malzemeleri / Yapıya Giriş | Teknik Resim, mimari anlatım |
| 2 | Mimari Tasarım II (konut / küçük ölçek) | Mimarlık Tarihi II (Rönesans–19. yy) | Yapı Elemanları / Yapı Teknolojisi I | Dijital modelleme, CAD |
| 3 | Mimari Tasarım III (kent / kamusal) | Modern Mimarlık Tarihi / Mimarlık Kuramı | Yapı Teknolojisi II, Çevre Kontrolü (ısı, ışık, ses) | BIM, parametrik tasarım |
| 4 | Mimari Tasarım IV (karma / bütünleşik) | Koruma / Rölöve / Seçmeli tarih | Yapı Yönetimi, detay, cephe | Portfolyo, görselleştirme |
| 5 (bazı programlarda) | Bitirme / Diploma | Seçmeli kuram | Seçmeli teknoloji | — |

The studio is the spine: technical courses are expected to feed the studio
project, not sit beside it. A note that teaches a technology topic without a
studio decision (a span, a detail, a facade, a section) is a reference page,
not a studio note.

## Where the misconceptions live

| Course | Recurring misconception | Note that fixes it |
|---|---|---|
| Temel tasarım | “Plan = drawing”; no section | plan–section cut lab; scale bar |
| Konut stüdyosu | net/gross area, circulation, privacy | adjacency/privacy lab; area ledger |
| Yapı teknolojisi | “Detail = decoration”; tolerance ignored | wall assembly + tolerance stack |
| Çevre kontrolü | “Render = daylight”; U-value unit confusion | sun path / DF; U-value lab |
| Mimarlık tarihi | timeline as list of dates | tectonic anatomy; comparative plan |
| Koruma | “Restoration = style choice” | significance/compatibility matrix |
| Kent | “FAR is the only density measure” | solar envelope + shadow trade-off |

## Studio assessment vocabulary

A studio jury asks: What is the **parti**? What is the **sectional move**? What
is the **threshold**? How does the **structure** meet the **envelope**? Who is
**excluded**? What is the **precedent**, and what did you change? A note that
uses this vocabulary prepares the student for the critique, not just the exam.
