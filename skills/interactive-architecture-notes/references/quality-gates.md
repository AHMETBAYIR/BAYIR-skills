# Quality gates — architecture

Run these before delivery. A page that fails a gate is not finished.

## Content

- [ ] Lede names studio year, site/program, and payoff.
- [ ] 3–5 outcomes, observable, not “understand”.
- [ ] One formal definition and one worked example.
- [ ] One plan–section–elevation triad or a detail.
- [ ] One design claim ledger with counter-arguments.
- [ ] One constraint table with type/edition/clause/unit.
- [ ] One precedent at the same scale (if the note analyzes one).
- [ ] 3+ common mistakes, each with a counterexample.
- [ ] 6–10 retrieval questions with cause-specific explanations.
- [ ] 3–5 exercises with hidden solutions.
- [ ] One-screen summary.
- [ ] Sources for every external claim and drawing.

## Drawing

- [ ] Plan is a cut, section is a cut, elevation is a projection.
- [ ] Scale bar on every plan/section; north arrow on site/floor plans.
- [ ] Cut elements poché; beyond-cut lighter.
- [ ] Dimension chain closes; units stated; mm vs m consistent.
- [ ] Stair/ramp: R, 2R+G, headroom, landing, width, risers per flight.
- [ ] Grayscale print still readable.
- [ ] “Şematik / not to scale” where true.

## Lab

- [ ] Prediction before controls.
- [ ] One design move per lab.
- [ ] Reset, keyboard, `prefers-reduced-motion`.
- [ ] Canvas has `role="img"` and a changing `aria-label`.
- [ ] Status line explains the cause, not just the number.
- [ ] Readout has units and the governing constraint.
- [ ] `?selftest=1` passes.
- [ ] No console errors.
- [ ] No external data/analytics.

## Responsive / print

- [ ] 390 px: no horizontal overflow; controls wrap; tables scroll.
- [ ] 1200 px: lab is not stretched; drawing has margins.
- [ ] Dark mode: line/label contrast.
- [ ] Print: controls hidden; current state, scale bar, ledger visible.
- [ ] No lab split across pages; no table row split.
- [ ] A4 portrait default; A3 landscape for drawing sheets if needed.

## Accuracy

- [ ] Every number has a unit and a family (code/convention/teaching).
- [ ] Code edition/clause is present.
- [ ] No invented dimension, material, site condition, or precedent.
- [ ] No render presented as a calculation.
- [ ] No copyrighted drawing reproduced without permission.
- [ ] Model limits stated at the point of use.

## Delivery

- [ ] Absolute path.
- [ ] What is inside (sections, labs, precedent, ledger).
- [ ] One honest caveat.
- [ ] Print command and checker path.
