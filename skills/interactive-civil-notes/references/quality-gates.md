# Quality gates — civil engineering

Run these before delivery. A page that fails a gate is not finished.

## Content

- [ ] Lede names course, level, system, and payoff.
- [ ] 3–5 outcomes, observable, not “understand”.
- [ ] Number-family box (characteristic/design/allowable).
- [ ] Load-combination table (if gravity/lateral).
- [ ] Limit-state ledger with demand, capacity, ratio, governing row, clause.
- [ ] One worked example with a unit balance.
- [ ] One collapse-mode sketch.
- [ ] 3+ common mistakes, each with a counterexample.
- [ ] 6–10 retrieval questions with cause-specific explanations.
- [ ] 3–5 exercises with hidden solutions.
- [ ] One-screen summary.
- [ ] Sources for every standard value, soil parameter, and dataset.

## Lab

- [ ] Prediction before controls.
- [ ] One limit state or one mechanism per lab.
- [ ] Real solver, not a lookup table.
- [ ] `C=T`, `ΣF=0`, `ΣM=0`, `s≤s_max`, `ε_s≥ε_yd`, `V_d≤V_r≤V_max`.
- [ ] Reset, keyboard, `prefers-reduced-motion`.
- [ ] Canvas `role="img"` and changing `aria-label`.
- [ ] Status line names the governing limit and the cause.
- [ ] `?selftest=1` passes.
- [ ] No console errors.
- [ ] No external data/analytics.

## Responsive / print

- [ ] 390 px: no horizontal overflow; controls wrap; ledger scrolls.
- [ ] 1200 px: lab is not stretched; ledger readable.
- [ ] Dark mode: line/label contrast.
- [ ] Print: controls hidden; ledger and governing row visible.
- [ ] No lab split across pages; no table row split.
- [ ] Grayscale-safe semantic colours.

## Accuracy

- [ ] Every number has a unit and a family.
- [ ] Code edition/clause present.
- [ ] No invented material, soil, water, traffic, or table value.
- [ ] No FEA/BIM claim without a model.
- [ ] Ductility/brittle mode stated.
- [ ] Model limits stated at the point of use.
- [ ] Copyright: only a small cited subset of a standard table.

## Delivery

- [ ] Absolute path.
- [ ] What is inside (sections, labs, worked example, ledger).
- [ ] One honest caveat.
- [ ] Print command and checker path.
